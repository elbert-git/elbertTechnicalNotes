# UI Design
UI Design
---------

A small part of  experience design. This the design of visual interfaces for screens. It is better to view this subset of UX 

Design is not art
-----------------

UI design is meant to be used. It's meant to get out of the way and facilitate the intended experience as much as possible. Most of the time it's creating a pleasant and fuss free experience. And this often involves pretty visuals

UI design is Design so see the [Dieter ram's principles of design](../General%20Design%20Notes/Dieter%20Ram's%20Principles%20of%20Goo.md)

Visual communication
--------------------

UI design today is mostly in the screen medium. So best to know how to use this screen canvas. See how you can manipulate objects to create an intended experience by these [variables.](../General%20Design%20Notes/Design%20and%20Human%20Perception.json)

The process
-----------

### Wireframes and user journeys

Start with what you want the user to do and quickly layout wireframes

### Mock-ups

Actually designing the winning wireframe to the fullest.

### Prototyping

Quickly test out the design with figma prototypes.

### Developer handover and overseeing
