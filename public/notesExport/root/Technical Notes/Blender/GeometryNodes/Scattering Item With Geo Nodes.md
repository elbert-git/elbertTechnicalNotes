# Scattering Item With Geo Nodes
It's basically just create point instances and adding instances on points. 

You can use the scatter on objects but this will scatter by the surface. 

you can also convert mesh into volume and scatter on volume

Realize instances
-----------------

This nodes helps you treat every instance as different data. cause when you display stuff  you or change colors etc. you want all of the instances to be unique

Orienting instances to normals
------------------------------

you can use the normals node to get the normals and pass it through a normals to euler node to get the rotation of the instance on points

Mesh Line (Array modifier)
--------------------------

Mesh line creates an array of vertices for you to put instances on. You can use this like an array modifier
