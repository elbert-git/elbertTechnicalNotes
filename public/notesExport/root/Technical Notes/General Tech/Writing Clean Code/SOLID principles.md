# SOLID principles
Solid principles
----------------

A set of  guideline to create clean OOP code in programs. Popularly described by Robert J. Martin (aka uncle bob) in his book, ‘Clean Code and Clean Architecture’. 

| Principle | Short Explanation |
| --- | --- |
| Single Responsibility | Every class should do only one thing. Or have one reason to change |
| Open/Closed | Classes should be to easy to extend without modifying what is already written |
| Liskov Substitution |     |
| Interface Segratation |     |
| Dependency inversion | avoid dependency hell. should be as modular as possible |
