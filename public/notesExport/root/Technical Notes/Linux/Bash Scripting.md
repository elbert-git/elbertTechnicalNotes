# Bash Scripting
The shell of linux
------------------

This is the main languag of using linux and how you use the linux shell. Short for bourne-again shell

Be wary of Spacing
------------------

Do note that spaces are very important in bash. Dumb syntax errors are mostly made by spaces

When in doubt
-------------

### Help

Prints a quick documentation on bash features

```text-plain
help grep
```

### Apropos

Find the most appropriate program for what you need

```text-plain
Apropos audio # searches for audio related programs
```

This works by querying all the manual pages for the word

### Man

```text-plain
man ls
```

prints out documentation for the program
