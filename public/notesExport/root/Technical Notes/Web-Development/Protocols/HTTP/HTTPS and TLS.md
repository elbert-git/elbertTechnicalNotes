HTTP is open by default
-----------------------

HTTP is a public communication tool first. Mean you can snoop into other's requests since it's a public ping. To get around this, people encrypt their messages before sending it

TLS
---

is the common standard agreement of how creating secure encrypted channels between server and client

HTTPs
-----

is just a certificate signed by a security agency to verify yes TLS is working
