A new paradigm of creating full stack applications

### The Previous way

You'd create a full interactive single page application with react or the like along with your back end. This has some drawbacks.

1.  more loading times, as you are downloading a full web app on load
2.  SEO is a challenge since the ui is rendered after Javascript rather than just parsing the html

### What NextJS solves

Next js is just react but you can pick and choose what you render statically on the server and what can be dynamic on runtime. The best of both worlds

Setup
-----

```text-plain
npx create-next-app@latest ./
```
