# Next JS App Directory
Aside from react, this is kind of the main mechanic of Next JS

General Intuition
-----------------

The most important directory is the App directory. This is how you create pages and api endpoints. you don't specify them in code. you create them by managing your directory. see the routing page for more details

### Creating a page. 

Just create a `src/apppage.tsx/jsx` and the react compoenent inside is the web page

```text-plain
export default function HomePage(){
  return(
    <div>
      <h1>Hello m8</h1>
      <p>your mother</p>
    </div>
  )
}
```

### Creating a layout

You also need a layout page for every route. This encompasses your page.tsx and whatever sub things are inside. you can create your headers and footers here

```text-plain

import './style.css'; // you shoudl also import your css here


// this is the title metadata in link previews

// like in discord link previews
export const metadata = {
  title: 'Next.js',
  description: 'Generated by Next.js',
}

export default function RootLayout({
children,
}: {
children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>
        <div className="header">Elbert Notes</div>
        <Link href={'/notes'}>Notes</Link>
        {children}
        <div className="footer">This is my foot</div>
      </body>
    </html>
  )
}
```

There are other reserved file names that server different functions

| File name | Description |
| --- | --- |
| error.tsx | for when errors occur. this will render by default |
| loading.tsx | for when loading content this will load first |

Defining routes
---------------

### Just Directories and function components

After creating a next js project you should have an `app/` directory. That is the default route `/` of your app. To add more routes like `/about`. Just simply make another directory called about

So you directories will look like this

*   app/
    *   `page.tsx`: This is the component to render in the page. the root home page
    *   about/
        *   `page.tsx`: this will render in the “/about”
    *   contact/
        *   `page.tsx`: this will render in the “/contact”

### layout and page

In a route directory. You should most commonly have 2 files. layout.ts and page.ts. 

|     |     |
| --- | --- |
| page.tsx | This is the component to render in a page. |
| layout.tsx | This is a wrapping component. It contains the page.tsx component and all children directories. |

Linking between routes
----------------------

Import the link tag

```text-plain
import Link from 'next/link';
```

Create a link tag.

```text-plain
<Link href="/about">
	<div>Link to about page</div>
<Link>
```

Urls would be relative to the main domain.
