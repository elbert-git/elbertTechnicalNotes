# Back-end
Backend in a Nutshell
---------------------

Back-end in software development is usually the data storage and the logic to manipulate it. This covers the topics such as Databases, [Authentication](Back-end/Authentication%20in%20node.md), [Server Endpoints](Protocols/RestfulAPIs.md) etc.

Interacting with the back-end
-----------------------------

Typically the backend is hosted and run on a distant server from the user. And its interacted it with the internet. 

Here are some of the protocols used to interact with it

*   [HTTP](Protocols/HTTP.md)
*   [WebSockets](Protocols/Websockets.md)
*   [GraphQL](Protocols/GraphQL.md)
