# Python Virtual Envrionments
In General
----------

It's just a contained folder with all python dependencies like packages and libraries. Different projects require different versions of libraries. Environments just compartmentalize all the dependencies for each of them. 

This is kinda like node projects. 

Virtual Environment Tools
-------------------------

Most tools seems to be an extension of the default virutalenv. 

| Tools | Description |
| --- | --- |
| env | The most basic default tool |
| poetry | a more elegant implementation of envs |
| conda | A tool preffered by the ML terms |
