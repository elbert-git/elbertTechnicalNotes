# Stable Diffusion (AI Image generation)
Stable Diffusion
----------------

An open source suite of tools for text to art. Using Nvidia Gpus

Installation
------------

The git repo is just a python project so just make sure you have python installed on your machine

[Github Repo](https://github.com/AUTOMATIC1111/stable-diffusion-webui) to clone

Just clone and run the web ui script. `webui-user.bat` for windows and `webuser-ui.sh` for linux

The Output Folder
-----------------

In the stable diffusion directory you can see all the images you created, edited. basically everything you generated. 

The info tab
------------

you can insert images you generated and get the prompt and generation metadata out.
