# Tailwind features above CSS
States
------

```text-plain
<button class="bg-sky-500 hover:bg-sky-700 ...">
  Save changes
</button>
```

Just prefix the classes by the state

*   hover
*   active
*   focus

Or anythign with the colons in css

Responsive design
-----------------

in built breakpoinst you can put. just like above just prefix the classes

```text-plain
<img class="w-16 md:w-32 lg:w-48" src="...">
```

| prefix | width | desc |
| --- | --- | --- |
| sm  | <640px | phone screen and below |
| md  | <768px | tablet and below |
| lg  | <1024px | laptop monitor and below |
| xl  | <1280px | large monitor and below |
| 2xl | <1536px | widescreen and below |
