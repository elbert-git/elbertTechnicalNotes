# MongoDB
MongoDB
-------

A document based database. Basically a bunch![MongoDB gets a data lake, new security features and more | TechCrunch](MongoDB_MongoDB_Logo_FullColor.png) of nested json documents

The database, shell and mongoose
--------------------------------

To run the mongoDB install from [here](https://www.mongodb.com/docs/manual/installation/). But to actually interact with it you need to use the shell or mongoose. Most of the time you won't be hosting the mongoDB on your webserver. Rather it's served somewhere. 

install the mongo shell [here](https://www.mongodb.com/docs/mongodb-shell/)
