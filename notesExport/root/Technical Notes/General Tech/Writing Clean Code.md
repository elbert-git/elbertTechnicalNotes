# Writing Clean Code
What is Clean Code?
-------------------

Code that is easy to:

*   Understand
*   Explain
*   Change
*   Test

How do you write clean code?
----------------------------

It's all about having a toolset of commonly understood patterns and principles. Like SOLID and Design Patterns

----------------------
