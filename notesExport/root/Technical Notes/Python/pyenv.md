# pyenv
In General
----------

This is pretty much nvm. lets you have a specific python version

only works on unix based OS-es at the moment

Installation
------------

```text-plain
curl https://pyenv.run | bash
```

Usage
-----

```text-plain
# installing a specific ver
pyenv install {ver}

# listing installs
pyenv install -l

# switching to version
pyenv global {ver}
```
