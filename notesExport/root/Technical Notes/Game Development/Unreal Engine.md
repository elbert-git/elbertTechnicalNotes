# Unreal Engine
Unreal Engine in General
------------------------

Unreal engine is a pretty opinionated game engine. it was designed to make games and only games at first. unlike the more general unity. But now it has diversified into a realtime animation and vfx tool. 

Installation and setup
----------------------

You install by the epic games launcher. which is horrible

General UI 
-----------

Very similar to unity. viewport is there. ctrl space to open the project file browser. On the right is the inspector zone

Actors
------

Actors are like higher level objects. Basically prefab roots like in unity. double click them to open their hierarchy and blueprint nodes. There are types of blueprints like actors, pawns and enemies. all with different set of built in functions and nodes. 

### Blueprints

This is how you create logic for the unreal engine. They are all event based flows. So like there will be `trigger` events. that you can chain functions from.
