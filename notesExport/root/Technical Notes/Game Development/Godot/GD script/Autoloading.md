# Autoloading
Godot Autoloading
-----------------

This is a persistent object that is in the background. Practially this could be a global state and background scene.

Creating an autoload variable
-----------------------------

```text-plain
var count = 0
```

Then go to proejct settigns under the autoload tab create an autolaod

Accessing the autolaod script
-----------------------------

```text-plain
globals.count
```
