# Unity
Unity ![Unity Real-Time Development Platform | 3D, 2D, VR & AR Engine](Unity_images.png)
----------------------------------------------------------------------------------------

The most widespread game-engine for game development

Installation
------------

Just google install unity and install it via the Unity hub

General Intuition
-----------------

Unity works on objects and components. Components are the scripts that describe the behaviours of the object. By default all objects are just transforms in space that you can manipulate. 

Unity is a [dotnet application using C#.](../C%23%20and%20Dotnet.md) but see here to have a better understanding [csharp in unity](Unity/(todo)%20C%23%20in%20unity.md)
