# Pico 8 Interface
The CLI
-------

This is the first thing that you see when you launch pico 8. 

press `escape` to go back to the game editor. 

press `ctrl+r` to run the game

##### Performance view

`ctrl+p` during the game's runtime to a debug of how fast your game is running. It should be at 30fps at all times. 

The Editors
-----------

There are 5 tabs on the top right corner of the screen. They are the 

*   Code Editor
*   Sprite Editor
*   Tile-Map Editor
*   Sound Editor
*   Music Arrangement Editor

TBH they are all well designed and visually self explanatory on how thy work

File Management
---------------

### Loading and Saving file

```text-plain
save {gameName}
load {gameName}
```

to load and save

`ctrl+s` to save the game
