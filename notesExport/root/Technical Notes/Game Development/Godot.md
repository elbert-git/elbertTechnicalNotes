# Godot
Godot![File:Godot icon.svg - Wikipedia](Godot_1200px-Godot_icon.svg.pn)

An open source game engine much like unity

The Node system
---------------

This is the main mechanic of godot. Where every node is just one component. Unlike Unity where object can have multiple components. In godot you attach nodes/object to other nodes to form your behavior
