# Machine Learning
Machine Learning
----------------

Machine Learning is the process of creating computer behaviors without actually programming it in. Where a normal program would have something like `if x>0: return True`. A machine learning interpretation would be feeding the program a bunch of numbers labelling it positive and negative then somehow it just learns whether or not it's positive or negative. The premiere technique is called [neural networks](Machine%20Learning/Neural%20Networks.md)
